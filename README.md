# NORTHVELT Clothing Production Landing Page

A responsive React + Vite landing page with a CSS-animated clothing-production illustration. It does not require a video or image asset.

## Run locally
1. Install Node.js (LTS).
2. Extract the project ZIP and open the folder in VS Code.
3. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build
```bash
npm run build
```
The production site is generated in `dist/`.

## Deploy to Render
1. Push the project to a GitHub repository.
2. In Render, choose **New → Static Site** and connect the repository.
3. Build command: `npm install && npm run build`
4. Publish directory: `dist`
5. Deploy.
